# Unpack.ai 🎓🤖
### Break Down Assignments. Understand the Task. Plan Your Success.

# Live Link: unpack-ai.co.za

**Unpack.ai** is an AI-powered academic assistant designed to help students understand complex assignment briefs by breaking them down into smaller, manageable tasks. The platform aims to make academic work less overwhelming by helping students identify requirements, organise their workload, and develop a clearer plan for completing assignments.

## 🚀 Project Overview

Students often struggle to interpret lengthy assignment instructions, identify key deliverables, and determine where to begin. Unpack.ai addresses this challenge by using AI to simplify assignment requirements and transform them into actionable steps.

The project explores the use of large language models (LLMs) and AI technologies, including **MzansiLM through Hugging Face**, to support a more accessible and structured learning experience.

## ✨ Key Features

- **📄 Assignment Breakdown** — Helps students interpret assignment briefs and identify the main requirements.
- **🧠 AI-Powered Assistance** — Uses AI and language models to support the analysis and simplification of assignment instructions.
- **✅ Task Organisation** — Structures assignment requirements into smaller, actionable steps.
- **📚 Student-Focused Design** — Focuses on making academic instructions easier to understand and follow.
- **🇿🇦 Local AI Exploration** — Explores the use of MzansiLM and Hugging Face for AI-powered educational support.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/) — JavaScript runtime
- npm — Package manager included with Node.js
- Git — Version control

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/KM-CODES23/Unpack.ai.git
```

**2. Navigate to the project directory**

```bash
cd Unpack.ai
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

> These commands assume your repository uses a standard npm-based React setup. Adjust them if your project uses a different framework or directory structure.

## 🔐 Environment Variables

If your application connects to an AI service or external API, store API credentials in environment variables rather than hardcoding them into your source code.

For example, a Vite application may use a `.env` file:

```env
VITE_API_URL=your_api_url
```

**Security reminder:** Never expose private Hugging Face access tokens or other secret API keys in frontend environment variables. Keep secrets on a backend server and add `.env` to `.gitignore`.
